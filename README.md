# nz-octopus

2D-аквариум, в котором живёт одна осьминожка с табличным Q-learning мозгом.
Она рождается полностью случайной и учится всю жизнь: искать еду, избегать
стен и не умирать от голода. Мозг сохраняется в `brain.json` — существо
помнит опыт между запусками.

## Запуск

```bash
uv run tui.py            # смотреть в терминале
uv run tui.py --fresh    # осьминожка рождается заново (пустой мозг)
uv run tui.py --speed 50 # больше тиков на кадр (быстрее обучение)
```

## Как устроено

- `sim/brain.py` — табличный Q-learning: состояния × действия → ценность.
  ε-greedy исследование затухает со временем, learning rate тоже.
- `sim/world.py` — непрерывный мир 80×30, еда, стены, метаболизм.
  Состояние для мозга: направление до ближайшей еды (8 + «не вижу») и
  дистанция (3 уровня). Награды: +10 еда, −2 стук о стену, −0.045/тик
  за рост голода, −50 голодная смерть (жёсткий респаун).
- `tui.py` — рендер аквариума в терминале (rich), статистика обучения.

## Что наблюдать

Молодая осьминожка мечется хаотично и часто умирает от голода. Через
несколько минут симуляции она начинает целенаправленно двигаться к еде —
следи за «epsilon (curiosity)» и «avg reward» в панели статистики.
